# 粘贴到公众号时，图片会怎样

一键粘贴模式把本地图片嵌进正文，用浏览器的选区复制放进剪贴板。公众号编辑器会把这些图片一起收进去。标题和封面不在这段正文里。

## 怎么复制才带得上图

可用的做法和本仓库完整流水线的预览页一样：

1. 正文节点里的 `<img>` 使用 `data:image/...;base64,...`。
2. 按钮在点击时用 `document.createRange()`、`selectNodeContents` 选中这个已经渲染好的节点，再调用 `document.execCommand('copy')`。
3. 这是一次真正的选区复制。浏览器会把屏幕上看到的内容，包括图片，放进剪贴板。公众号编辑器收下的是渲染结果，不是一段被改写过的 HTML 字符串。

手机浏览器同样走这一步。只有 `execCommand('copy')` 失败时，才退回 `navigator.clipboard.write`，把同一段 HTML 写进剪贴板。

不要改成先把 `innerHTML` 用 `clipboardData.setData('text/html')` 写进去。那样剪贴板里只剩地址字符串，编辑器不会像选区复制那样把图带上。

## 页面上各复制什么

| 区域 | 会不会进「复制正文」 | 做什么 |
| --- | --- | --- |
| 正文，含文中配图 | 会 | 点「复制正文」，到公众号正文里粘贴 |
| 标题 | 不会 | 点标题旁边的「复制标题」，填进公众号标题框 |
| 封面 | 不会 | 页面上标着「封面（在后台单独上传）」，用下载链接保存后在后台传 |

标题来自文首的 `title:`，否则用一级标题；没有一级标题就用第一处标题。这一处标题不会留在正文节点里。

封面可以用 `--cover 图片路径`，或写在文首：

```markdown
---
title: 文章标题
cover: assets/cover.jpg
---
```

## 备用原图

`images/` 里仍按文中顺序导出 `01-`、`02-` 开头的原图，封面另存为 `封面.jpg` 这类文件。这是备用。正文里的图会跟着选区复制过去；只有粘贴后发现缺图，才按这个文件夹手工补。

公网 `http` / `https` 图片保持原地址。编辑器若能访问该地址，会再转存一次，并可能压缩。
