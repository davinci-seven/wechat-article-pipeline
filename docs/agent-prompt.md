# 给ChatGPT、Claude或Codex的执行提示词

不在自己的电脑前时，也可以把文章和脚本直接交给支持代码执行的AI来完成排版。

如果你只想知道“发给ChatGPT时该说什么”，先看这一页就够了。

## 需要上传什么

建议一次上传这4类文件：

1. 定稿Markdown，最好命名为`终稿.md`
2. Markdown里引用的全部图片
3. `tools/render_wechat.py`
4. `tools/stitch_screenshot.py`

缺少图片时，AI无法完成图片检查和稳定版HTML；缺少脚本时，输出也不会与本项目保持一致。

## 一句话提示词

```text
读取我上传的Markdown、配图和公众号排版脚本，保持正文、图片顺序和图注不变。

请检查所有本地图片路径，并生成：
1.公众号兼容的内联HTML
2.图片内嵌、不依赖本地路径的发布稳定版
3.约390px宽的手机预览页
4.带一键复制按钮的浏览器预览
5.手机端完整长截图
6.图片证据表、原稿哈希和HTML校验报告

不要覆盖原始Markdown，不要创建公众号草稿。全部检查通过后，把结果打包成zip给我。
```

需要指定主题时，在最后补一句：

```text
使用red-white主题。
```

## 正文要求特别严时，再补这一段

```text
额外要求：
- 不改写、缩写或合并任何正文段落
- 不调整图片顺序和图注
- 排版前后分别计算原稿SHA256，并在报告中列出
- 任意图片缺失时停止执行，并明确列出缺失路径
- 不调用公众号发布接口
```

## 完成后怎么验收

把下面这段也一起发给AI，能明显减少“只回你一句已完成”的情况：

```text
请根据实际输出逐项汇报：
- 原稿SHA256前后是否一致
- 图片命中数量和总数量
- HTML校验的ERROR和WARNING数量
- 390px视口下是否存在横向溢出
- 生成了哪些文件

不要只写“已完成”，请引用实际检查结果。
```

## 本机脚本和AI执行的区别

| | 本机脚本 | 交给ChatGPT、Claude或Codex |
| --- | --- | --- |
| 速度 | 通常更快 | 通常需要几分钟 |
| 一致性 | 固定脚本执行，结果更稳定 | 取决于是否完整执行脚本和校验 |
| 环境 | 需要Python和gzh-design | 需要支持上传文件和执行代码 |
| 适用场景 | 日常出稿 | 临时在外、无法访问本机 |

日常使用优先运行`tools\公众号排版.ps1`。

真的不在电脑前，或者只想把文章直接扔给ChatGPT处理，再用这页的提示词就行。
